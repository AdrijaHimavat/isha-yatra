# Isha Yatra

A free, unofficial, fan-made 3D walk through Isha Yoga Center, playable in the browser: https://isha-yatra.vercel.app/

- `index.html` – the small loader page; its `GAME` line points to the current game file.
- `game-vN.html` – the game, one self-contained file per version. Older versions stay so that cached loaders keep working.

Every push to `main` is published by Vercel.
